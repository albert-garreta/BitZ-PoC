# Selected production qualification

**This candidate does not yet qualify.** Reduced arithmetic layouts are consistently faster, but the independent [batch-32 confirmation](../confirmation-batch32/README.md) reproduced small proof-time regressions in all four unchanged one-worker degree/security cases. The no-repeatable-regression criterion therefore requires an implementation fix before acceptance.

All **7,168 proofs verified** across **64 shapes**. Input digests matched for every pair. All **2,304 unchanged proofs** exactly matched the preserved v7 control; **1,280 proofs** used the reduced arithmetic layout and v8 transcript. Physical source bits, packed bytes and commitment roots remained unchanged for all inputs.

The shipping candidate enables arithmetic-padding reduction and uses the existing binding/bridge computation. Both variants use native release binaries with only `falcon-hybrid`. Failed experimental compact-computation pilots remain in the parent directory.

Each input had one warmup and three measured proofs, with 32 independent seeds for core-small shapes and eight for core-large and edge shapes. All timing processes ran sequentially with alternating variant order, pinned one/eight worker settings, and no concurrent builds, tests or analysis.

Positive percentages mean slower or larger. The table uses pooled-sample medians. `Proof paired 95%` is the seed-paired median bootstrap interval (10,000 resamples); intervals are descriptive and have no across-shape multiplicity adjustment. RSS is process peak memory, including preparation/external inputs.

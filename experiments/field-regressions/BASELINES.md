| Operation | Matching contract | Stronger control / limitation |
|---|---|---|
| GF128 add | Same GF(2^128), native 16-byte layouts. | Shared implementation. Compare against both consumers independently. |
| GF128 mul | Same GF(2^128), native 16-byte layouts. | Shared implementation; ARM scalar_lanes. Compare against both consumers independently. |
| GF128 square | Same GF(2^128), native 16-byte layouts. | Shared implementation. Compare against both consumers independently. |
| GF128 inverse | Same GF(2^128), native 16-byte layouts. Inverse uses nonzero inputs. | Shared implementation. Compare against both consumers independently. |
| GF128 delayed dot / MAC | XOR sum of unreduced products, one final field reduction. | Retain shared_wide1 incumbent and eager Flock as a secondary comparison. |
| GF128 fixed multiplier and butterfly | Same scalar/product or pair butterfly; scalar is explicitly public and fixed for the pass. | Benchmark actual private FixedGfMul through a frozen extraction; retain existing prepared formula as a control. |
| GF128/B127 fused sumcheck rounds and folds | Identical weighted coefficients and output buffers; a weighted pair is not one multiplication. | Generic unfused formula is a diagnostic; actual native fused hooks are the regression baseline. |
| Flock GF128 out-of-place pair folds | Same source offset, destination length and output layout. | F2Z in-place fold is a separate lifecycle, not a direct timing denominator. |
| GF8 scalar operations | AES polynomial basis; nonzero inverse domain for current measurements. | Existing ARM vector GF8 multiplication, exposed separately through a frozen wrapper, is a stronger batch control. |
| B127 scalar operations | GF(2^127) modulo X^127+X+1; high padding bit canonical. | Retain existing mul_karatsuba and mul_pfold as controls; all have the same field contract. |
| Bit and F2 arithmetic | Benchmark Boolean and F2 contracts separately; integer bit lifting is not a field embedding into odd characteristic. | Native bool/u64 packed operations as controls after matching lane and output contracts. |
| Packed F2 polynomial multiply and dot | Full carryless product with W_OUT >= W_A+W_B; no field reduction. | Bit-serial oracle outside timing; current native and portable product schedules as timed controls. |
| GF8 to GF128 embedding and explicit lifts | Exact existing embedding basis; zero extension is not phi8. | Fixed-address basis combination against current table embedding; classify private timing contract separately. |
| Binary-field powers and fixed-base preparation | Same exponent capacity/pattern, base reuse and output field. | Individual power and prepared FixedBasePow are separate public-input baselines. |
| Wrapping integer arithmetic and MAC | Arithmetic modulo 2^(64L); bounded fixtures may additionally have exact mathematical results. | Keep the winning two_limb_mac/selected and nine-limb fused kernel in every relevant development comparison. |
| Checked signed and unsigned integer arithmetic | Existing Option values include success/failure representation and mixed overflow classes. | Raw crypto-bigint CtOption checked operations for masked private-result comparisons; keep Option API timing separate. |
| Integer comparison and masked selection | Ordering, equality masks and selection are separate output contracts. | Native comparisons for 1/2 limbs; direct raw signed/unsigned masked operations for matching Ct results. |
| Integer shifts, bitwise operations and narrowing | Public versus private shift amounts and checked versus unchecked conversion are separate cases. | Raw crypto-bigint operations and primitive controls at matching width. |
| Exact unsigned wide products | All 2L output limbs, identical layout and no reduction. | Existing P-256 product is a separate 18-limb-output comparison; do not compare its time to a shorter output without accounting for writes. |
| P-256 bounded wide products | Four or nine public active limbs in nine-limb storage; all 18 output limbs written. | Compare with prepared_selected and validate_execute_selected from integer-focus-arm-03, plus raw widening multiplication at matching output width. |
| Exact signed/mixed products and exact MAC | A+B product limbs, A+B+1 accumulator limbs; bounded total product count. | Build a fixed-storage product-then-add reference; BigInt remains an independent oracle outside timing. |
| Unsigned division and remainder | Same quotient and remainder, divisor public for preparation; normalization/output padding included when required. | For 64-bit divisors compare prepared reciprocal; for public multi-limb divisors also compare div_rem_vartime, documented variable only in divisor. |
| Signed division and remainder | Truncation toward zero, signed remainder, MIN/-1 and zero-divisor validity. | Public-divisor variant separately; distinguish truncating remainder from canonical modular reduction. |
| Signed integer-to-prime projection | Canonical nonnegative residue of the same signed integer; q100/q128 and widths 2/4/9. | Fixed-storage crypto-bigint vartime division is an additional control, not an owned replacement. |
| Prime scalar arithmetic | Reduced Montgomery residues and same public modulus; compact versus configured layouts explicitly identified. | RawMontyCtx is the primary compact arithmetic baseline; configured MontyField and invariant-brand wrappers remain controls. |
| Prime product and native linear MAC | Field×field has R² scale, field×native integer has R scale; preserve the appropriate final reduction. | Keep one accumulator and acc4; small and large batches choose no winner until confirmation. |
| Prime accumulator reduction | One reduction of an accumulator constructed from 1,024 terms, not 1,024 reductions. | Crypto-bigint reference is retained as a slower control. |
| Prime × signed coefficient MAC | Existing helper requires coefficient magnitude <= u64::MAX despite an i128 argument. | For larger signed coefficients build a matching full-width reference; do not reinterpret a full-width unsigned Montgomery residue as signed. |
| Prime inverse and division | Nonzero elements for current loop; masked zero/nonunit outputs receive separate tests and timings. | Benchmark existing FixedMontyForm::invert as the matching private-input API control, plus prepared SafeGcdInverter reuse. |
| Prime powers | Identical exponent value, public bit bound, field and base reuse. | Prepared fixed-base candidate gets distinct setup and repeated-execution comparisons. |
| True batch inversion | One shared inversion; current helper leaves zeros zero and allocates prefix/output buffers. | Compare equivalent allocating calls, then separate scratch-reuse implementations with preparation cost reported. |
| Prime context setup | Known public prime; setup includes Montgomery constants and RawMontyCtx, not prime search. | Raw reuse measured separately from fresh construction. |
| Prime canonical codecs | Canonical standard residues, not raw Montgomery words; match width and validation. | Allocating wrapper and whole proof framing are separate baselines; private masked decoding needs a matching result contract. |
| Integer/binary codecs and conversion | Exact declared width/endianness, signed representation and padding-bit validation. | Raw copy controls measure transport only; retain canonical-validation and allocation costs in their own comparisons. |
| Complete additive NTT and setup | Identical transform shape, lane order, thread counts and reset lifecycle. | Keep native fused schedule primary; generic/scalar transforms are correctness or diagnostic controls. |
| Hybrid OOD evaluation and packed-buffer lifecycle | Identical packed layout/point, final field value and lifecycle; separate evaluation, packing, and composite costs. | Keep current blocked delayed-reduction evaluation; naive per-element multiplication is not the primary speed baseline. |
| General modular-ring arithmetic | Canonical residues for explicit odd/even/composite moduli; nonunits produce invalid inverse results. | Build fixed-storage add/mul/reduce reference compositions for absent owned-ring APIs. |
